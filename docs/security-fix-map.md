# Security Fix Map

This document is the S0 security surface inventory. It tracks memory safety,
FFI boundary, capability-reporting, and silent-fallback risks that must stay
visible before GPU, WASM, GUI, scoring exactness, or renderer work expands.

## Release Rule

Any risk marked release blocking must either be closed with a passing test named
in this map or remain visibly disabled with a diagnostic reason. A feature
outside MVP scope must never be presented as working by default.
